# /commit

Run `pnpm typecheck` and `pnpm test`. Fix any errors before proceeding.

Then stage all relevant changed files — exclude debug CSVs, `.env.local`, and any scratch files. Do not use `git add -A`; add files by name.

Write a conventional commit message (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`) with a body explaining the _why_. Commit.
